# 🌐 SECR1213 – Network Communications

## 📘 Course Brief
This course introduces fundamental concepts of computer networks and data communications based on the TCP/IP protocol stack. It covers both conceptual and technical aspects of networking using a top-down approach, including network usage, communication principles, and practical tools. Students gain understanding of how computer networks operate in real-world applications.

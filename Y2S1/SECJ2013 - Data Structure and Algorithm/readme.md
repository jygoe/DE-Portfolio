# 📚 SECJ2013 – Data Structures and Algorithms

## 📘 Course Brief
This course focuses on fundamental data structure concepts and algorithm design, including abstract data types, recursion, and algorithm efficiency analysis using Big-O notation. It covers linear structures such as stacks, queues, and linked lists, as well as non-linear structures like trees and binary search trees. Students apply sorting, searching, and problem-solving techniques through practical implementation in C++.

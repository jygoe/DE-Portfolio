# 🗄️ SECP2523 – Database (WBL)

## 📘 Course Brief
This course introduces database system concepts and focuses on designing and implementing databases for real-world applications. It covers database environment, entity-relationship diagrams (ERD), normalization, and SQL. Students develop database applications using DBMS tools through conceptual, logical, and physical database design phases.

# 🧑‍💻 SECP3204 – Software Engineering (WBL)

## 📘 Course Brief
This course introduces software engineering principles and engineering approaches to developing high-quality software systems. It covers software development life cycles, requirements engineering, system design, and testing using structured documentation and UML techniques. The course emphasizes producing complete software artifacts such as SRS, SDD, and STD as part of a full system development process.

# 🌐 SECP3723 System Development Technology (WBL)

## 📘 Course Brief
This course focuses on web-based system development using PHP, HTML, CSS, and Bootstrap. It emphasizes full-stack development skills including front-end design, back-end logic, database integration, and system deployment through real-world group and individual projects.

# 🧩 Projects

## 🏦 KKK Online System (Group Project)
A web-based cooperative management system developed for Koperasi Kakitangan KADA (KKK).

### ✨ Features
- Member registration and management  
- Financial and cooperative service handling  
- Admin dashboard for system control  
- Responsive UI using Bootstrap  
- PHP-based backend with database integration  

---

## 🎓 Course Registration System (Individual Project)
A web application that allows students to register and manage course enrollment.

### ✨ Features
- Student course registration  
- Course update and management  
- Lecturer approval of course applications  
- Admin management of courses and lecturers  
- Role-based access control (Student / Lecturer / Admin)  
- CRUD operations using PHP & MySQL  
- Responsive Bootstrap interface  

---

### 🧠 Technologies Used (Both Projects)
- PHP  
- HTML  
- CSS  
- Bootstrap  
- MySQL

# 💭 Reflection
- **What I learned:** I learned how to build full web systems using PHP and integrate frontend and backend components into functional applications.
- **Challenges:** Handling database relationships and managing dynamic user interactions were the most challenging parts.
- **Takeaway:** Working on both individual and group systems helped me understand real-world system development workflows and teamwork in software engineering.

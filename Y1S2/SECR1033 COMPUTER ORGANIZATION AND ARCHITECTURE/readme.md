# 🖥️ SECR1033 Computer Organization & Architecture (COA)

## 📘 Course Brief
This course introduces the fundamentals of computer architecture and assembly language programming. It focuses on low-level programming concepts, CPU operations, registers, and instruction execution using Assembly Language.

---

# 📁 Assignments & Project

- 📄 [Lab 1](./Lab%201/) – Assembly language fundamentals including 32-bit, 16-bit, and 8-bit arithmetic operations (addition and subtraction).
- 📄 [Lab 2](./Lab%202/) – Arithmetic operations and register-level inspection through step-by-step debugging.
- 📄 [Lab 3](./Lab%203/) – Advanced assembly programming using loops, conditional jumps, and library procedures, including interactive menu-based programs.

---

# 💻 Project

- 📄 [Project](./COA%20Project%20Code/) – Performance benchmarking and comparison of computer systems using tools like CPU-Z, Geekbench, and Task Manager, supported by an assembly-based stress test program.

---

## 🧠 Lab Summary

### 🔧 Lab 1 – Assembly Fundamentals
- 32-bit signed addition and subtraction
- 32-bit unsigned integer operations
- 8-bit and 16-bit arithmetic operations
- Understanding basic CPU register behavior

### ⚙️ Lab 2 – Arithmetic & Debugging
- Step-by-step execution tracing
- Register content analysis
- Understanding instruction-level operations

### 🔁 Lab 3 – Control Flow & Libraries
- Loop implementation in Assembly
- Conditional jumps (AND, LOOP instructions)
- Perimeter calculator for hexagons
- Even/odd index summation
- Menu-driven combined program

- **What I learned:** I learned how CPU-level instructions execute and how assembly language interacts directly with hardware components like registers and memory.
- **Challenges:** Understanding low-level debugging and managing register states was difficult at first.
- **Takeaway:** Assembly language gives deep insight into how computers actually process instructions at the hardware level.

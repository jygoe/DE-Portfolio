# 📐 SECP2613 – System Analysis and Design (WBL)

## 📘 Course Brief
This course provides a practical approach to systems analysis and design using structured and object-oriented methodologies. It covers system development phases including planning, analysis, design, and implementation. Students learn to analyse system requirements, design input/output/interface structures, and develop prototype solutions for organizational systems.

# 📊 SECI1143 – Probability & Statistical Data Analysis (PSDA)

## 📘 Course Brief
This course introduces statistical techniques for data analysis using real-world data. It covers descriptive statistics, probability, hypothesis testing, correlation, and regression analysis. Students apply statistical methods using R programming to analyse and interpret data effectively.

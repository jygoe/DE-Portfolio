## 🧾 Course Brief    
This course introduces students to problem-solving techniques using a structured programming approach. It focuses on developing programming skills in C++ to solve simple to moderate problems. **Name: Elevator Controller System**  
This project involves developing C++ programs based on case study analysis. We selected two cases: a student grading system that processes final exam results and assigns grades, and a sales analysis program that evaluates company sales performance. Both programs apply structured programming concepts such as input/output operations, control structures, functions, and arrays to solve real-world problems.

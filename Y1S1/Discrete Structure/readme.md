# 📘 SECI1013 - Discrete Structure

## 🧾 Course Brief  
This course introduces the fundamental concepts of discrete structure in computer science, including set theory, proof techniques, relations, functions, recurrence relations, counting methods, graph theory, trees, and finite automata. It equips students with the ability to solve computational problems using mathematical reasoning and discrete models, as well as apply these concepts in areas such as algorithms, data structures, and system modeling.

---

## 📝 Assignments
- [Assignment 1](./Assignment%201.pdf/) – Set theory problems involving operations and logical quantifiers (∃, ∀) to solve mathematical expressions.
- [Assignment 2](./Assignment%202.pdf/) – Problems on relations, functions, and recurrence relations involving analysis and problem solving.
- [Assignment 3](./Assignment%203.pdf/) – Applications of pigeonhole principle, probability, and graph theory including paths and cycles.

# 📘 SECR1013 - Digital Logic

## 🧾 Course Brief  
This course teaches us about the fundamentals of digital electronics, which form the basis of microprocessor-based systems used in computers, robots, automobiles, and industrial control systems. It introduces key digital concepts, components, and tools, ranging from basic principles to programmable logic devices. The course also provides hands-on laboratory experience using simulation software and real circuits to reinforce understanding of digital systems.

# 📁 Labs & Project

- 📄 [Lab 1 – Combinational Logic](./Lab%201%20circuit.pdf) – Basic breadboarding and implementation of logic gates (AND, OR, NOT, NAND, XOR) using hardware circuits.

## 💻 Project
**Name: Elevator Controller System**  
This project designs a digital elevator control system using sequential logic circuits for a hotel environment. Users select a destination floor (0–7) and must authenticate using either a room card (NFC simulation) or a passcode before the elevator operates. The system uses components such as comparators, SR latches, counters, and flip-flops, and is simulated using Deeds software. It demonstrates the application of digital logic in building a secure and automated elevator control system.

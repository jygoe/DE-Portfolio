# 🐍 Data Analytics Programming

## 📘 Course Brief
This course introduces Python programming for data analytics, focusing on data manipulation, cleaning, visualization, and basic machine learning. Students learn to use libraries such as Pandas, NumPy, Matplotlib, and Seaborn to analyze real-world datasets and extract meaningful insights.

---

# 📁 Assignments & Project

- 📄 [Assignment 1](./Assignment%201.ipynb) – Ride-sharing data analysis using Python, focusing on file handling, functions, lambda expressions, and generating ride and driver insights.
- 📄 [Assignment 2](./Assignment%202.ipynb) – Retail sales data analysis using Pandas, including sorting, filtering, grouping, aggregation, and multi-index operations.
- 📄 [Assignment 3](./Assignment%203.ipynb) – Rainfall data analysis using Pandas, NumPy, Matplotlib, and Seaborn to explore trends and visualize regional rainfall patterns.
- 📄 [Final Project](./project.ipynb) – Data integration of vehicle datasets to analyze fuel consumption and emissions using EDA, clustering (KMeans), and classification (Random Forest).

---

# 💭 Reflection
- **What I learned:** I learned how to use Python for real data analysis, including cleaning, transforming, visualizing, and modeling data.
- **Challenges:** Handling messy datasets and interpreting model outputs were the most challenging parts.
- **Takeaway:** Python is a powerful tool for turning raw data into actionable insights through analysis and visualization.

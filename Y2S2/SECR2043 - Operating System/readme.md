# 💻 SECR2043 – Operating System

## 📘 Course Brief
This course introduces the fundamental concepts of operating systems, which act as an interface between computer hardware and users. Topics include process management, concurrency and synchronization, deadlock handling, memory management, file systems, secondary storage management, and I/O management. Students learn the algorithms and techniques used in operating system design and implementation through both theory and practical exercises.

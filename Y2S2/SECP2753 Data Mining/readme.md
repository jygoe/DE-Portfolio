# 📊 Data Mining

## 📘 Course Brief
This course introduces the fundamental concepts of data mining and knowledge discovery in databases (KDD). It covers key techniques such as classification, clustering, and association analysis, along with machine learning applications, model evaluation, and real-world data mining workflows.

---

# 📁 Activities & Projects

- 📄 [Project 1 – Classification](./Data%20Mining%20Project%201.pdf) – Implementation of classification models (Decision Tree, SVM, Random Forest) with performance evaluation using Accuracy, Precision, Recall, and F1-score.
- 📄 [Project 2 – Clustering](./Data%20Mining%20Project%202.pdf) – Clustering analysis using K-Means and GMM with evaluation metrics such as Silhouette Score, DBI, Dunn Index, and WCSS.

---

# 💭 Reflection
- **What I learned:** I learned how data mining techniques are used to extract patterns from large datasets, including classification and clustering methods.
- **Challenges:** Understanding evaluation metrics and comparing different machine learning models was challenging.
- **Takeaway:** Data mining is essential for transforming raw data into meaningful insights that support decision-making.

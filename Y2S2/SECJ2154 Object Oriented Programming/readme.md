# 🛒 Project: Console-Based Online Shopping Cart System

This project is a Java-based console application that simulates an e-commerce shopping cart system using Object-Oriented Programming principles.

### 🧩 Features
- 🛍️ Customers can browse and add items to shopping cart
- 🧾 Cart management and checkout process
- 👨‍💼 Admin can manage products and view/update orders
- ⚙️ Exception handling for system stability
- 📦 Uses Java Collections Framework (ArrayList, etc.)

### 🧠 OOP Concepts Used
- Classes & Objects  
- Encapsulation  
- Inheritance  
- Polymorphism  
- Exception Handling  
- Java Collections Framework

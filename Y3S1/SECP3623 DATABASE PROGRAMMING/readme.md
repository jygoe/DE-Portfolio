# 🗃️ SECP3623 – Database Programming

## 📘 Course Brief
This course introduces database programming concepts and techniques for developing efficient database-driven applications. Topics include relational databases, indexing, query optimization, transaction management, concurrency control, stored procedures, and NoSQL databases. Practical work is carried out using MySQL and MongoDB to design, implement, and optimize database systems.

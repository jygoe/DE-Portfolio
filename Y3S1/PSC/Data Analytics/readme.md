# 📊 Data Analytics for Organisation

## 📘 Course Brief
This course introduces data analytics concepts and focuses on using Tableau to transform raw data into meaningful visualizations and interactive dashboards to support organizational decision-making.

---

# 📁 Project

- 📄 [Data Analytics for Organisation Project Dashboard](./Group%208%20Data%20Analytics%20for%20Organisation%20Project.pdf) – Interactive dashboard and data visualization project developed using Tableau to analyze household income data across different states.
- 📊 [Tableau Workbook](./Group%208%20Data%20Analytics%20for%20Organisation%20Project.twbx) – Tableau project file containing dashboards, charts, and analysis.
- 🗂️ [Dataset](./hh_income_state%20(1).csv) – Raw dataset used for analysis, and visualization.

# 💭 Reflection
- **What I learned:** I learned how to use Tableau to create dashboards, build visualizations, and extract insights from real-world datasets.
- **Challenges:** Choosing suitable chart types and designing dashboards that are both informative and easy to understand.
- **Takeaway:** Data visualization is an important skill that helps transform raw data into meaningful insights for decision-making.

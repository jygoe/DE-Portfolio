# 🏢 SCSP3744 – Enterprise System Design and Modeling

## 📘 Course Brief
This course focuses on enterprise information systems (EIS) and how organizations design, integrate, and manage enterprise-level solutions. It covers enterprise architecture, system integration, value chain modeling, and real-world enterprise system implementation considerations. Students analyze business processes and design integrated solutions using industry-relevant case studies and tools.

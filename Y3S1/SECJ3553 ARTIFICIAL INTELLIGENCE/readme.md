# 🤖 SECJ3553 – Artificial Intelligence

## 📘 Course Brief
This course introduces the fundamental concepts and applications of Artificial Intelligence (AI). It covers key topics such as knowledge representation, intelligent agents, state space search, and machine learning techniques. Students learn how to formulate AI problems, design intelligent solutions, and apply AI concepts to real-world scenarios through assignments and project-based learning.

---

# 📁 Assignments

- 📄 [Assignment 1](./Assignment%201.pdf) – Knowledge Representation (KR) using First-Order Logic (FOL), including logical rules, predicates, and reasoning to support the proposed AI solution
- 📄 [Assignment 2](./Assignment%202.pdf) – State Space Search formulation, including states, actions, goal states, path costs, and search graph representation
- 📄 [Assignment 3](./Assignment%203.pdf) – Intelligent Agent design using the PEAS model (Performance Measure, Environment, Actuators, and Sensors)

---

# 📂 Project

- 📄 [Project Proposal](./Project%20Proposal.pdf) – Design Thinking proposal for **Rydit: Learn Mandarin**, an AI-assisted Mandarin learning platform that uses handwriting recognition, adaptive learning, spaced repetition, and gamification
- 📄 [Final Report](./Final%20Report.pdf) – Complete AI solution design for Rydit, applying knowledge representation, intelligent agents, adaptive feedback systems, and state space search to improve Mandarin character learning

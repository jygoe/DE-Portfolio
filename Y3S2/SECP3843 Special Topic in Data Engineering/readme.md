# ⚙️ SECP3843 Special Topic in Data Engineering

## 📘 Course Brief

This course provides practical exposure to modern data engineering technologies, cloud platforms, big data processing, machine learning applications, and industry-driven data solutions. Students learn how to design and implement end-to-end data pipelines using industry-standard tools while gaining insights through industrial visits, guest lectures, and real-world projects.

Throughout the semester, hands-on experience was gained in Microsoft Azure, Apache Spark, Agentic AI, machine learning workflows, dashboard development, and cloud-based data engineering architectures.

# 💭 Reflection

* **What I learned:** At the beginning of the course, I learned how to write a technical report academically and professionally by research the article from multiple source, like Google Scholar and Web of Science. From technical perspective, I learned how modern data engineering solutions are built using cloud technologies, big data tools, machine learning techniques, and business-oriented data pipelines. The course provided practical exposure to latest technologies, such as Azure services, Apache Spark, AI-assisted development, and dashboard visualization.

* **Challenges:** Integrating multiple cloud services and troubleshooting configuration issues was often challenging and time-consuming for a beginner, especially when working with Azure services and external dependencies. Understanding how business requirements translate into technical implementations also required careful analysis. Besides, there is also a need to always adapt with latest technologies to make the system more efficient.

* **Takeaway:** Data engineering is more than simply moving data between systems. It involves designing scalable architectures, processing data efficiently, applying business logic, and delivering actionable insights. The most important in constructing a data pipeline is that we need to understand the business requirement first before starting to build anything. This course provided valuable exposure to real-world tools and practices used in modern data-driven organizations, this would definitely encourage us to keep learning and improving.

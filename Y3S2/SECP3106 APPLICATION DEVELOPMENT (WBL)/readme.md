# 📱 Application Development (WBL)

## 📘 Course Brief
This course focuses on the development of modern software applications through work-based learning (WBL). Students apply software engineering principles, UI/UX design, database integration, and mobile application development techniques to solve real-world problems for actual clients. The course emphasizes requirement gathering, system implementation, testing, deployment, and client collaboration throughout the development lifecycle.

---

# 📁 Project

## 👩‍🏫 Teacher Management System (Flutter)

A mobile application developed for a kindergarten principal to streamline teacher administration, performance evaluation, and daily operations. The system was built using Flutter and designed based on real client requirements gathered through discussions with the kindergarten management team.

🔗 **Project Repository:**  
https://github.com/tanyiya/teacher-management-system

### ✨ Admin (Principal) Features
- Assign training programs to teachers
- Manage teacher registrations and profile documents
- Review teacher reports and submissions
- Evaluate teacher performance
- Automatically calculate final KPI scores
- Assign duties and tasks to teachers
- Manage teacher leave applications
- Monitor teacher progress and activities

### ✨ Teacher Features
- Apply for leave
- View assigned daily duties and tasks
- View monthly KPI performance summaries
- Apply for available training programs
- Submit maintenance reports
- Submit work-related reports and updates
- Manage personal profile information

### 🛠 Technologies Used
- Flutter
- Dart
- Firebase
- Cloud Firestore

### 🎯 Key Learning Outcomes
- Requirement gathering from real clients
- Mobile application development using Flutter
- Role-based access control implementation
- KPI calculation and performance evaluation logic
- State management and form validation
- Firebase integration and cloud database management
- Real-world software development workflow

---

# 💭 Reflection
- **What I learned:** This project provided valuable experience in working with a real client and translating business requirements into a functional mobile application. I learned how to design workflows that support both administrative and teacher operations within a single system.

- **Challenges:** One of the biggest challenges was designing the KPI evaluation logic and ensuring that different user roles could only access the functionalities relevant to them. Managing changing requirements from the client throughout development was also challenging.

- **Takeaway:** This project strengthened my understanding of full application development, client communication, requirement analysis, and Flutter development. It also demonstrated how software can improve operational efficiency by automating administrative and performance management processes.

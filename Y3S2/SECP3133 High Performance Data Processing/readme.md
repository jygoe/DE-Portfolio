# ⚡ SECP3133 High Performance Data Processing

## 📘 Course Brief
This course explores high-performance data processing techniques for handling large-scale datasets efficiently. Topics include parallel computing, performance optimization, cloud technologies, distributed systems, data processing frameworks, and scalable data pipelines. Through assignments and projects, students gain practical experience in optimizing data workflows and evaluating modern data engineering technologies.

## 🚀 Project 1 – Property Data Processing & Optimization Benchmark

- 📄 [Project Report](./Project%201)

A large-scale property analytics project involving web scraping, data processing optimization, and performance benchmarking.

### Data Collection
- Developed a web scraper using BeautifulSoup.
- Scraped property listings from Mudah.my.
- Collected **102,468 records** across **17 attributes**.
- Built a structured property dataset for analysis.

### Optimization Techniques Evaluated
- Pandas (Baseline)
- Pandas (Optimized)
- Polars
- DuckDB

### Performance Evaluation

The project benchmarked multiple data processing frameworks based on:

- Execution Time
- Memory Consumption
- Throughput
- Scalability

### Results

🏆 **Polars achieved the best overall performance**


### Key Learning Outcomes
- Large-scale web scraping
- Data pipeline optimization
- Benchmarking analytical frameworks
- Memory-efficient data processing
- Performance engineering for analytics workloads

# 💭 Reflection

This course provided valuable exposure to performance-oriented data engineering and large-scale data processing. The web scraping project demonstrated how different processing frameworks can significantly impact execution speed and resource consumption when working with large datasets. Through benchmarking Pandas, Polars, and DuckDB, I gained practical experience in selecting appropriate technologies based on workload requirements.

The course also strengthened my understanding of cloud technologies through AWS training and certifications, while introducing modern data engineering concepts such as streaming pipelines and distributed processing. Overall, it broadened my perspective beyond traditional data analytics and highlighted the importance of scalability, optimization, and system performance in real-world data applications.
